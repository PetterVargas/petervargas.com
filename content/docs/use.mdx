## Software

### Sistema operativo

- **Ubuntu Desktop** (última versión) — [ubuntu.com/desktop](https://ubuntu.com/desktop "ubuntu.com/desktop") — lo uso desde el 2007 (Inicié en Ubuntu 7.04 LTS)

### Editor y desarrollo

- **VS Code** — [code.visualstudio.com](https://code.visualstudio.com/ "code.visualstudio.com").
- **Claude Code** — [claude.com/claude-code](https://claude.com/claude-code "claude.com/claude-code").
- **pnpm** — [pnpm.io](https://pnpm.io/ "pnpm.io"), como gestor de paquetes.
- **GitHub** — [github.com](https://github.com/ "github.com"), como repositorio de código.

### Gestión de proyectos

- **Linear** — [linear.app](https://linear.app/ "linear.app"), para la gestión personal de mis proyectos.

### Terminal / Shell

- **Oh My Zsh** — [ohmyz.sh](https://ohmyz.sh/ "ohmyz.sh"), con el tema [fishy](https://github.com/ohmyzsh/ohmyzsh/blob/master/themes/fishy.zsh-theme "fishy").
- **Plugin tmux** — [plugin tmux de Oh My Zsh](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/tmux "plugin tmux de Oh My Zsh") para manejar múltiples ventanas en el terminal.

### Navegador

- **Google Chrome** — [google.com/chrome](https://www.google.com/chrome/ "google.com/chrome").

### Infraestructura

- **Cloudflare DNS** — [dns.clouflare.com](https://www.cloudflare.com/es-la/application-services/products/dns/ "dns.clouflare.com"), para registros, reglas y WAF.
- **Cloudflare Pages** — [pages.cloudflare.com](https://pages.cloudflare.com/ "pages.cloudflare.com"), para el hosting de mis proyectos.
- **Cloudflare Workers** — [cloudflare.com/products/workers](https://www.cloudflare.com/products/workers/ "cloudflare.com/products/workers"), para funciones serverless.
