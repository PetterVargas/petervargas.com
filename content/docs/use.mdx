## Hardware

### Escritorio y cómputo

- **Escritorio artesanal de pino de 2.5 metros** — hecho en Pereira.
- **Portátil** — Dell i7, con tarjeta gráfica dedicada, 32 GB de RAM y 1 TB de estado sólido — [dell.com/laptops](https://www.dell.com/en-us/shop/laptops/sc/laptops).
- **Pantalla** — [Samsung](https://www.samsung.com/monitors/).
- **Teclado** — [Logitech](https://www.logitech.com/en-us/keyboards.html).
- **Mouse vertical** — [Logitech MX Vertical (910-005449)](https://www.logitech.com/en-us/products/mice/mx-vertical-ergonomic-mouse.html).
- **Tablet** — [Lenovo Idea Tab 11" (TB336ZU, modelo ZAFM0226CO)](https://www.lenovo.com/us/en/p/tablets/android-tablets/idea-tab-series/lenovo-idea-tab/len103l0028).

### Almacenamiento

- **Memorias de alta velocidad** — un poco arcaico, pero me gusta segmentar mis proyectos instalando el sistema operativo en memorias con buena velocidad de lectura/escritura, una por proyecto.

### Audio y streaming

- **Micrófono** — [Blue Yeti](https://www.logitechg.com/en-us/products/streaming-gear/yeti-premium-usb-microphone.html).
- **Brazo de micrófono** — [Aokeo AK-49](https://aokeo.com/product-category/accessories/microphone-stands-arms/).
- **Cámara (webcam)** — [Logitech HD](https://www.logitech.com/en-us/webcams.html) (aunque en mi vida personal no pienso usarla mucho).
- **Cámara para fotos** — celular [Xiaomi Redmi Note 14 Pro Plus 5G](https://www.mi.com/global/product/redmi-note-14-pro-plus-5g/).

## Software

### Sistema operativo

- **Ubuntu** (última versión) — lo uso desde Ubuntu 7.04 LTS.

### Editor y desarrollo

- **VS Code** — [code.visualstudio.com](https://code.visualstudio.com/).
- **Claude Code** — [claude.com/claude-code](https://claude.com/claude-code).
- **pnpm** — [pnpm.io](https://pnpm.io/), como gestor de paquetes.
- **GitHub** — [github.com](https://github.com/), como repositorio de código.

### Terminal / Shell

- **Oh My Zsh** — [ohmyz.sh](https://ohmyz.sh/), con el tema [Gallifrey](https://github.com/ohmyzsh/ohmyzsh/blob/master/themes/gallifrey.zsh-theme).
- **Plugin tmux** — [plugin tmux de Oh My Zsh](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/tmux) para manejar múltiples ventanas en el terminal.

### Navegador

- **Google Chrome** — [google.com/chrome](https://www.google.com/chrome/).
- **Brave** — [brave.com](https://brave.com/).

### Infraestructura

- **Cloudflare** — [cloudflare.com](https://www.cloudflare.com/), para la infraestructura de mis proyectos.

### Voz y accesibilidad

- **Voxtype** — [voxtype.io](https://voxtype.io/), para escribir con voz.

### Grabación y edición de video

- **OBS Studio** — [obsproject.com](https://obsproject.com/), para grabar el escritorio, con el plugin [Zoom to Mouse](https://github.com/BlankSourceCode/obs-zoom-to-mouse).
- **DaVinci Resolve** — [blackmagicdesign.com/products/davinciresolve](https://www.blackmagicdesign.com/products/davinciresolve).
- **Wayscriber** — [wayscriber.com](https://wayscriber.com/), para dibujar sobre la pantalla.

### Video programático

- **Hyperframes** — [hyperframes.app](https://hyperframes.app/).
- **Remotion** — [remotion.dev](https://www.remotion.dev/).

### Documentación y presentaciones

- **Fumadocs** — [fumadocs.dev](https://fumadocs.dev/).
- **Slidev** — [sli.dev](https://sli.dev/).

### Seguridad y extensiones

- **LastPass** — [lastpass.com](https://www.lastpass.com/), como gestor de contraseñas y extensión de navegador.
- **Wappalyzer** — [wappalyzer.com](https://www.wappalyzer.com/), extensión de navegador.
- **Generador de Contraseñas** — [herramientas.divisioncero.com/generador-contrasenas](https://herramientas.divisioncero.com/generador-contrasenas).
- **Generador de QR** — [herramientas.divisioncero.com/generador-qr](https://herramientas.divisioncero.com/generador-qr).

### Notas

- **Blog de notas** — lo uso todo el tiempo para apuntes.
